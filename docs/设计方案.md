\## 🎨 二、全局 UI/UX 设计规范

\### 1. 极简科技风格 \& 黑白双主题

\- \*\*色彩系统\*\*：仅使用 `#000000`、`#FFFFFF`、`#111111`、`#F5F5F5`、`#333333` 作为主色，辅以 `#00D1B2`（科技青）作为唯一交互高亮色。

\- \*\*视觉质感\*\*：微玻璃拟态（Glassmorphism）+ 1px 极细描边，卡片圆角统一 `12px`，阴影仅用于层级区分（`shadow-sm`/`shadow-md`）。

\- \*\*主题切换\*\*：顶部导航栏右侧提供 `🌗 主题切换` 按钮，切换时通过 CSS `transition: background 0.3s, color 0.3s` 平滑过渡，无闪烁。

\## 🖱️ 五、交互细节与 Tooltip 规范

1\. \*\*触发逻辑\*\*：桌面/平板 `Hover 300ms` 显示，移动端 `长按 500ms` 或 `点击 ⓘ 图标` 显示。

2\. \*\*样式规范\*\*：背景 `#111`（白主题）/ `#EEE`（黑主题），文字 `#FFF`/`#111`，圆角 `6px`，最大宽度 `280px`，箭头指向触发源。

3\. \*\*内容结构\*\*：`\[图标] 功能简述` + `⚡ 注意事项/边界条件`。

4\. \*\*无障碍\*\*：所有 Tooltip 绑定 `aria-describedby`，支持屏幕阅读器朗读，ESC 键可关闭。

\## ⚡ 六、性能与高可用保障（功能优先下的优化）

| 维度 | 策略 | 预期指标 |

|------|------|----------|

| \*\*首屏加载\*\* | 路由懒加载 + 图片 WebP/AVIF + 关键CSS内联 | LCP ≤1.2s，FCP ≤0.8s |

| \*\*抽奖响应\*\* | Redis 缓存活动配置 + WebSocket 推送 + 乐观UI更新 | 点击到动画触发 ≤80ms |

| \*\*高并发\*\* | 抽奖队列异步化（RabbitMQ/Kafka）+ 分布式限流（Sentinel） | 峰值 10W QPS 不丢单 |

| \*\*离线容灾\*\* | PWA 缓存核心页面 + 抽奖记录本地持久化 + 网络恢复同步 | 断网可参与，恢复后自动补单 |

| \*\*主题切换\*\* | CSS Variables 动态覆盖，零 JS 阻塞，`prefers-color-scheme` 自动跟随 | 切换无闪烁，性能损耗 <2ms |
